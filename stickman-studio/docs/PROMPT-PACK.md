# Prompt pack — English motivational scripts that fit this studio

Each entry is ready to paste into the **Script** tab. Mentioning the bracketed
keywords is what makes the parser pick the right poses, props and sets.

## 1 · The 5 AM story (bundled demo, 15 s)

```
Scene 1 (3s): A digital alarm clock reads 5:00 AM on the nightstand and rings while he sleeps in bed.
Scene 2 (2.6s): He wakes up, reaches for his phone and slides back under the blanket.
Scene 3 (2.6s): Text card: ANOTHER DAY WASTED.
Scene 4 (4.3s): He gets up, puts the phone away and exercises with dumbbells in front of the mirror.
Scene 5 (2.5s): Text card: DISCIPLINE STARTS WITH ONE CHOICE.
```

### Writing tips that the parser understands

| Write this | You get |
|---|---|
| `(3s)` or `duration: 3` | that beat's length (default 3 s) |
| `sleep / bed / blanket` | lying-in-bed pose on the bed prop, bedroom set |
| `alarm / clock / 5:00 / ring` | alarm clock prop with ringing ripples |
| `wake up` | sit-up-in-bed pose, bedroom set |
| `phone / scroll` | phone prop, hands holding it |
| `work / desk / laptop / study` | desk office set, typing pose |
| `exercise / dumbbell / curl / squat / jumping jacks / push-up` | exercise poses + weights |
| `run / walk / stairs / climb` | locomotion and stairs/gym sets |
| `fail / quit / wasted / lazy` | slump, knees, collapse poses |
| `celebrate / win / success / proud` | fists-up and jump-tuck celebrations |
| `mirror` | mirror prop that reflects the actor |
| `text card: SOMETHING` | a title card with automatic red emphasis |

Put `**double asterisks**` around the words you want in red on a card, or leave it
to the generator (it emphasises the last two or three punchy words).
