Costs & accounts

  • No paid service or API key is required for preview, audio synthesis or MP4 export.
  • FFmpeg is resolved automatically: $FFMPEG_PATH → system ffmpeg → the @ffmpeg-installer npm package → a one-time download of the same public static build.
  • Optional: narration needs a voice recording (your own mic, or any TTS you already pay for). Nothing in the app is gated behind an account.
